# 🏪 Ritelindo Group — B2B High-Converting Landing Page

> **Mini Test Web Developer Intern — PT Ritelindo Akselera Kolaborasi**  
> Dibuat oleh: **Fauzil Azhim**

Landing page B2B berkonversi tinggi untuk **PT Ritelindo Akselera Kolaborasi (Ritelindo Group)** — produsen & suplier rak gondola minimarket, rak gudang, dan perlengkapan display retail komersial langsung dari pabrik.

---

## 🌟 Nilai Proposisi Utama (Value Propositions)

1. **Harga Pabrik Langsung (Factory Direct):** Efisiensi biaya 20–30% lebih hemat dibandingkan distributor perantara.
2. **100% Free Desain Layout 3D:** Simulasi tata letak lorong rak, modul rak, dan sirkulasi troli presisi gratis sebelum transaksi.
3. **Free Ongkir Seluruh Jawa & Bali:** Pengiriman armada pabrik aman & tepat waktu.
4. **Free Perakitan & Pemasangan:** Teknisi ahli mencakup Jawa Timur (Jatim), Jawa Tengah (Jateng), dan DIY Yogyakarta.
5. **Kualitas Plat SPCC Cold-Rolled:** Finishing *powder coating* tahan gores dengan kapasitas beban teruji hingga 80 kg/ambalan.

---

## 🚀 Fitur Unggulan

- **Interactive Store Setup Calculator:** Estimasi kebutuhan modul rak, meja kasir, dan anggaran biaya setup toko secara *real-time* berdasarkan luas ruangan toko (m²). Terintegrasi langsung dengan WhatsApp konsultasi.
- **Retail Sectors & Customer Personas:** Navigasi interaktif 8 sektor bisnis ritel (Minimarket, Sembako, Baby Shop, Apotek, Pet Shop, Toko ATK, Bahan Kue, Toko Bangunan) dan 3 persona target (Owner Baru, Upgrade Modern, Buka Cabang).
- **3D Spherical Dome Gallery:** Animasi kubah 3D interaktif pada desktop menampilkan portofolio mitra waralaba nasional (Alfamart, Indomaret, AEON, FamilyMart, Mayora, Wings Group).
- **Dual-Track Infinite Marquee:** Tampilan mobile yang ultra-responsif, rapi, dan cepat dengan *eager decoding* rendering.
- **Floating Conversion Trigger:** Tombol WhatsApp mengambang dengan *pulse indicator* dan *prefilled intent message* untuk konversi Google Ads B2B maksimal.

---

## ⚡ Optimasi Performa & SEO Teknis (B2B Standard)

- **86.2% Asset Size Reduction:** Seluruh aset visual (JPG & PNG) dikonversi ke format modern **WebP** dengan kompresi berkualitas tinggi (ukuran total terpangkas dari **11.25 MB** menjadi hanya **1.55 MB**).
- **Zero Render-Blocking Stylesheets:** Menggunakan `<link rel="preconnect">` dan `<link rel="stylesheet">` non-blocking di `layout.tsx` untuk First Contentful Paint (FCP) instan.
- **Full Static Prerendering (SSG):** Dibangun dengan arsitektur statis Next.js App Router untuk Time to First Byte (TTFB) super cepat.
- **Schema.org Structured Data:** JSON-LD mencakup entitas `LocalBusiness`, `FAQPage`, `ProductCatalog`, dan `BreadcrumbList`.
- **Open Graph & Twitter Cards:** Dilengkapi metadata media sosial lengkap untuk preview share profesional.

## 💻 Panduan Instalasi Lokal

1. **Clone repositori:**
   ```bash
   git clone https://github.com/fauzilxx/Ritelindo.git
   cd Ritelindo
   ```

2. **Install dependensi:**
   ```bash
   npm install
   ```

3. **Jalankan server pengembangan:**
   ```bash
   npm run dev
   ```
   Buka [http://localhost:3000](http://localhost:3000) pada browser Anda.

4. **Build untuk Produksi:**
   ```bash
   npm run build
   npm run start
   ```

## 🌐 Deployment (Vercel)

Proyek ini telah dikonfigurasi dan dioptimasi secara *native* untuk platform **Vercel**:
1. Impor repositori GitHub `fauzilxx/Ritelindo`.
2. Pilih framework preset **Next.js**.
3. Klik **Deploy** tanpa memerlukan pengaturan *environment variable* tambahan.
