## 📌 Tentang Website

Website ini dirancang khusus sebagai landing page B2B (*Business-to-Business*) siap konversi untuk **PT Ritelindo Akselera Kolaborasi (Ritelindo Group)**. Website ini disiapkan untuk mendukung *traffic* iklan berbayar (seperti Google Ads B2B) dengan sasaran 3 segmen konsumen utama:
1. **Pemilik Minimarket Baru** yang membutuhkan paket perlengkapan toko lengkap.
2. **Pemilik Toko Kelontong Tradisional** yang ingin *upgrade* menjadi toko modern.
3. **Pebisnis Retail Berpengalaman** yang sedang membuka cabang toko baru.

Landing page ini berfokus pada penyampaian nilai proposisi kuat, transparansi estimasi biaya, kemudahan klaim desain layout 3D gratis, dan integrasi tombol aksi langsung ke WhatsApp tim sales.

## 📑 Struktur & Isi Halaman Website

Halaman disusun dalam satu alur cerita terpadu (*single-page storytelling*) dengan transisi visual yang mulus:

### 1. Header & Navigasi Cepat (Navbar)
- Identitas brand Ritelindo dengan tipografi modern.
- Navigasi menu pintar: **Katalog Produk**, **Keunggulan**, **Kemitraan**, **Paket & Biaya**, **Testimoni**, dan **FAQ**.
- Tombol aksi utama (*Call to Action*): **"Hubungi Kami"** langsung terhubung ke WhatsApp resmi.

### 2. Hero Section
- Judul utama yang menekankan keunggulan harga langsung dari pabrik.
- Highlight 4 fasilitas gratis: **Free Desain Layout 3D**, **Free Ongkir Jawa–Bali**, **Free Perakitan (Jatim, Jateng, DIY)**, dan **Garansi Mutu Pabrik**.
- Pratinjau visual modern suasana minimarket berstandar nasional.

### 3. Katalog Produk Modular (Featured Products)
Menampilkan 6 kategori perlengkapan display retail komersial:
- **Rak Gondola Single Dinding:** Rak display yang menempel pada dinding toko.
- **Rak Gondola Double Island:** Rak display tengah lorong (2 sisi).
- **Meja Kasir Modern & Showcase:** Meja kasir estetik dengan panel bergaris kayu dan travertine.
- **Rak End Gondola Semicircular:** Rak penutup ujung island lorong belanja.
- **Rak Display Aksesoris Pegboard:** Rak gantung untuk aksesoris, ATK, dan produk kecil.
- **Rak Heavy Duty & Gudang:** Rak penyimpanan stok gudang berkapasitas 250–500 kg per ambalan.
- Dilengkapi detail spesifikasi teknis dan tombol **"Tanya Brosur"** pada setiap produk.

### 4. Pilar Keunggulan Ritelindo (Why Ritelindo Deck)
Interaksi kartu bertumpuk (*stacking card deck*) yang menjelaskan 5 pilar utama mengapa pengusaha ritel memilih Ritelindo:
1. **100% Free Konsultasi & Denah Layout 3D:** Simulasi lorong belanja dan peletakan rak gratis sebelum pembelian.
2. **Produsen Langsung (Harga Pabrik):** Efisiensi biaya 20–30% lebih murah tanpa perantara distributor.
3. **Gratis Ongkos Kirim Se-Jawa & Bali:** Dikirim langsung menggunakan armada truk pabrik sendiri.
4. **Gratis Perakitan di Lokasi:** Tim teknisi ahli siap merakit langsung di toko (area Jatim, Jateng, DIY).
5. **Standar Plat SPCC Cold-Rolled:** Plat baja tebal dengan *powder coating* oven tahan karat dan beban 80 kg/ambalan.

### 5. Jaringan Mitra & Waralaba (Company Partnership)
- **Tampilan Desktop:** Animasi bola kubah 3D berputar interaktif (*3D Spherical Dome Gallery*) berisi deretan logo mitra nasional.
- **Tampilan Mobile:** Animasi berjalan dua arah (*dual-track infinite marquee*) yang ringan dan responsif.
- Memperlihatkan kepercayaan jaringan ritel besar seperti **Indomaret, Alfamart, AEON, FamilyMart, K3 Mart, Mayora, Wings Group, dan Kopdeskel**.

### 6. Sektor Bisnis Retail & Solusi Persona (Retail Sectors)
Tab interaktif untuk menyesuaikan kebutuhan rak berdasarkan jenis bidang usaha:
- **8 Sektor Usaha:** Minimarket Modern, Toko Kelontong/Sembako, Baby Shop, Apotek & Farmasi, Pet Shop, Toko ATK, Toko Bahan Kue, dan Toko Bahan Bangunan.
- **3 Persona Target:** Owner Toko Baru, Upgrade Toko Tradisional, dan Ekspansi Cabang Baru.

### 7. Paket Setup Toko & Kalkulator Biaya Interaktif (Store Calculator)
- **Katalog Paket Toko:**
  - *Paket Starter (Toko 30–45 m²)*
  - *Paket Standard (Toko 45–75 m²)*
  - *Paket Flagship (Toko 75–120 m²)*
- **Kalkulator Biaya Real-Time:** Pengunjung dapat memasukkan luas ruangan toko (m²), memilih tipe paket rak, dan menambahkan opsi meja kasir/software POS. Kalkulator menghitung estimasi jumlah rak dan total investasi secara otomatis, lengkap dengan tombol **"Kirim Rincian ke WhatsApp"**.

### 8. Testimoni Klien & Ulasan Nyata
Review asli dari para pemilik toko mandiri dan jaringan waralaba mengenai kepuasan kualitas rak, presisi denah 3D, dan kecepatan perakitan teknisi.

### 9. FAQ (Pertanyaan yang Sering Diajukan)
Jawaban transparan untuk calon pembeli mengenai:
- Syarat dan ketentuan Free Ongkir Jawa & Bali.
- Tata cara klaim desain 3D gratis.
- Jangkauan wilayah bebas biaya perakitan.
- Ketahanan beban dan garansi pabrik.

### 10. Footer & Galeri Showroom
- Alamat kantor pusat dan showroom utama di Lingkar Timur, Sidoarjo (akses 20 menit dari Bandara Juanda).
- Jam operasional dan kontak WhatsApp 24 jam.
- Menu navigasi sosial media interaktif (Instagram, TikTok, LinkedIn, YouTube, WhatsApp).

### 11. Tombol WhatsApp Mengambang (Floating Action Button)
Tombol WhatsApp mengambang di pojok kanan bawah dengan indikator aktif (*pulse animation*) untuk mempermudah calon pembeli berkonsultasi kapan saja.

## 💻 Panduan Penginstalan & Menjalankan Proyek

Pastikan Anda telah menginstal **Node.js** (versi 18.18 atau lebih baru) di komputer Anda.

### 1. Clone Repositori
Buka terminal dan unduh repositori dari GitHub:
```bash
git clone https://github.com/fauzilxx/Ritelindo.git
cd Ritelindo
```

### 2. Instal Dependensi
Pasang seluruh dependensi proyek yang dibutuhkan:
```bash
npm install
```

### 3. Menjalankan di Mode Pengembangan (Localhost)
Jalankan server pengembangan:
```bash
npm run dev
```
Buka browser dan akses alamat:
```
http://localhost:3000
```

### 4. Build untuk Mode Produksi
Untuk memeriksa hasil kompilasi statis dan menjalankan versi produksi:
```bash
# Melakukan build Next.js App Router
npm run build

# Menjalankan server hasil build
npm run start
```
